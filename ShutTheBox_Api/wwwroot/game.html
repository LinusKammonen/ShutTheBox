Hur man spelar

  1. Kasta tärningarna och lägg ihop resultatet.
  2. Fäll ner valfri öppen bricka, eller en kombination av brickor, vars summa matchar tärningskastet.
  3. Fortsätt att slå och fälla brickor så länge det finns ett giltigt drag kvar.
  4. Omgången tar slut när du har fällt alla brickor, eller när inga öppna brickor kan matcha summan.
  5. Ju lägre kvarvarande poäng desto bättre – att stänga hela lådan ger ett perfekt spel.
