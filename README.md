# Shut the Box

Frontenden byggdes först mot ett färdigt API som en skoluppgift. I det här projektet har jag skapat en egen backend med hjälp av AI: spelmotor, REST-API och realtidsuppdateringar med SignalR. 

## Stack

- **Backend:** C# / ASP.NET Core Web API, SignalR
- **Frontend:** HTML, CSS och JavaScript

## Hur man spelar

- Varje spelare har en egen låda med brickorna 1–9.
- Slå tärningarna och stäng brickor vars summa är lika med kastet.
- Spelaren fortsätter tills alla brickor är stängda eller inga giltiga drag finns.
- Poängen är summan av de öppna brickorna. Lägst poäng vinner.

## Kom igång

Klona ner projektet och öppna sedan http://localhost:5162 och logga in med valfritt användarnamn. Öppna ett inkognitofönster med ett annat namn för att testa multiplayer.
